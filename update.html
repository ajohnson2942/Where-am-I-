One-time phone setup

Your phone needs a limited GitHub token so this page can update the shared status file.

  1. Open GitHub’s fine-grained token page.
  2. Give the token access only to the where-am-I- repository.
  3. Under repository permissions, set Contents to Read and write.
  4. Create the token, copy it, and paste it below.
GitHub is connected on this phone.

The token stays in this browser and is sent only to GitHub.
